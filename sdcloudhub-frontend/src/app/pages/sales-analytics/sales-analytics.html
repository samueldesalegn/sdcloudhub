Sales performance, end to end — from raw CSV to BI.

An analytics pipeline built entirely as infrastructure-as-code: raw sales data lands in S3, a Glue ETL job curates it to partitioned Parquet, Athena queries it, and QuickSight visualizes it. Below is the resulting dashboard and the story it tells.

How it's built. Raw S3 → Glue ETL (PySpark, partitioned Parquet) → Glue Data Catalog → Athena workgroup → QuickSight. The entire backend — buckets, catalog, ETL job, Athena workgroup, a Lambda data-quality gate, and the embedding API — is defined in a single AWS SAM template and deployed through GitHub Actions. Partitioning uses Athena partition projection, so no crawler is needed.
